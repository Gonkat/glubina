# Замена спрайтов без изменения исходной графики

Все оригинальные PNG из проекта сохранены. При запуске игра использует именно их.
Никаких дополнительных изображений для работы не требуется.

## Как заменить один спрайт

1. Положите новый PNG в `assets/sprites/custom/`, например `custom/my_player.png`.
2. Откройте `assets/sprite_manifest.json`.
3. Для ключа `player` измените `file` с `player.png` на `custom/my_player.png`.
4. Нажмите F5 в игре. Другие спрайты останутся прежними.

Чтобы вернуть оригинал, восстановите `file: player.png` и нажмите F5.

Поддерживаются PNG, JPG, WEBP (при поддержке pygame), GIF (требует Pillow).
Если путь неверный, оригинальная резервная отрисовка сохраняет прежние цвета объектов.

Не нужно удалять или перезаписывать исходные изображения.

# Замена звука файлом из интернета (WAV / OGG / MP3)

Игра читает все звуки из `assets/sounds/`. Каждый звук в коде имеет имя,
например `soundbank.play("shoot")` — этому имени соответствует файл
`assets/sounds/shoot.wav` (их генерирует `python assets_gen.py`).

Чтобы заменить звук:

1. Скачайте нужный файл (WAV, OGG или MP3) и положите его
   в `assets/sounds/` **с тем же именем**, что и оригинал:
   `shoot.mp3`, `explosion.ogg` и т.д.
2. Запустите игру — новый файл подхватится автоматически.

Если рядом лежат два файла с одним именем (`shoot.wav` и `shoot.mp3`),
играется приоритетный: **mp3 > ogg > wav**. Оригинальные WAV можно не
удалять — они просто игнорируются.

Имена звуков, которые ждёт код:

| Где звучит | Имена файлов |
|---|---|
| Оружие | `shoot`, `shotgun`, `sniper`, `reload`, `swing`, `throw` |
| Бой | `hit`, `enemy_die`, `hurt`, `explosion` |
| Артефакты | `dash`, `shield`, `lightning`, `artifact` |
| Предметы / экономика | `coin`, `pickup`, `heal`, `buy`, `error` |
| Интерфейс | `ui_move`, `open`, `close` |

Битый или чужой файл пропускается молча: остальные звуки продолжают
работать, игра не падает.

# Спрайт оружия ближнего боя в руке

Оружие ближнего боя отображается в руке отдельным PNG-спрайтом:

1. Положите файл в `assets/sprites/weapons/` **с именем КЛЮЧА оружия**
   (ключ из `weapon_data.py`, а не название): `shovel.png`, `knife.png`,
   `machete.png`, `katana.png`, `hammer.png`, `shield.png`.
2. Ориентация — как у стволов: смотрит **вправо**, центр картинки
   совпадает с центром героя. Рекомендуемый размер 50–60 px в ширину.
3. Нажмите F5 в игре — спрайт подхватится без перезапуска.

Для метлы (`shovel.png`) в проекте уже есть отдельный спрайт с черенком
и щетиной. Он увеличивается на 8% с каждым уровнем улучшения, до 32% на
максимальном уровне. `python assets_gen.py` создаёт спрайт метлы, если файла
нет; `python assets_gen.py --overwrite` перерисовывает его вместе с огнестрелом.
Если спрайта другого оружия нет, в руке оно не отображается.
