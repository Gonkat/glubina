# ГЛУБИНА

Тёмный top-down шутер на Python + pygame: выживи, заработай, спустись
глубже. Мир освещается фонариком, оружие развивается собственными ветвями,
а каждый спуск делает сектор злее.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Нужен Python 3.13+ и pygame 2.6.1. Игра работает и без папки `assets/`:
недостающие спрайты и звуки заменяются процедурными.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| ЛКМ | огонь / заряд / заброс диска (удержание — заряд пушки) |
| ПКМ | удар оружием ближнего боя |
| Space | рывок с неуязвимостью |
| R | перезарядка |
| V | режим огня пистолета (ветвь «Арсенал») |
| Q / G | граната / аптечка |
| F | активный артефакт |
| X | приём оружия ближнего боя |
| E | маяк / магазин |
| T | доска навыков |
| Esc | пауза |

## Оружие

Огнестрельное: пистолет, дробовик, снайперская винтовка, энергопушка,
магнитный диск, дуговая пушка, плазменный резак.
Ближний бой: нож, мачете, катана, молот, метла, щит.

Каждое оружие имеет собственную механику и дерево развития из пяти-шести
ветвей по двадцать узлов — всего 1320 узлов.

## Документация

- `SKILL_MASTERY.md` — устройство древ, мастерство и связи ветвей;
- `ARSENAL.md` — концепты и механики новых стволов;
- `CANNON_TREE.md`, `PISTOL_TREE_V3.md`, `SKILL_TREE_V2.md` — история
  проектирования отдельных школ;
- `GRAPHICS.md` — графика, освещение и настройки рендера.

## Тесты

```bash
python -m pytest -q
```

Проверки headless: механики оружия, древа, раскладка доски навыков,
магазины, настройки графики.
