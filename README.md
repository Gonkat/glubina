# ГЛУБИНА

Тёмный top-down шутер на Python + pygame: выживи, заработай, спустись
глубже. Мир освещается фонариком, оружие развивается собственными ветвями,
а каждый спуск делает сектор злее.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Нужен Python 3.13+ и pygame 2.6.1. `PyOpenGL` необязателен: без него игра
запускается в CPU-режиме. Если папка `assets/` отсутствует, недостающие
спрайты и звуки заменяются процедурными заглушками.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| ЛКМ | огонь / заряд / заброс диска |
| ПКМ | удар оружием ближнего боя |
| Space | рывок с неуязвимостью |
| R | перезарядка |
| V | режим огня пистолета |
| Q / G | граната / аптечка |
| F | активный артефакт |
| X | смена оружия ближнего боя |
| E | маяк / магазин / лифт |
| T | доска навыков |
| Esc | пауза |

## Что есть в игре

- 13 школ оружия: 7 огнестрельных и 6 ближнего боя;
- 66 ветвей и 1320 узлов развития;
- процедурные сектора, комнаты, коридоры и магазины;
- 7 типов обычных врагов и 3 босса;
- артефакты, гранаты, элитные враги, система комбо;
- спуск по секторам с ростом сложности;
- CPU-рендер и опциональный OpenGL-режим с выбором адаптера.

## Структура

```text
main.py                 точка входа
game.py                 игровой цикл и состояния
player.py               герой, движение, инвентарь
weapons.py              оружие, заряд, режимы
projectiles.py          пули, взрывы, частицы
enemies.py / bosses.py  враги и боссы
world.py                процедурные чанки и коллизии
hud.py                  интерфейс
graphics_backend.py     CPU/OpenGL-вывод
assets/                 спрайты, звуки и manifest
```

`video_settings.json` создаётся игрой локально и не входит в репозиторий.
