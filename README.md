# ГЛУБИНА

Тёмный top-down шутер на Python + pygame: выживи, заработай, спустись
глубже. Мир освещается фонариком, оружие развивается собственными ветвями,
а каждый спуск делает сектор злее.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Нужен Python 3.13+ и pygame 2.6.1. `PyOpenGL` необязателен: без него игра
запускается в CPU-режиме. Если папка `assets/` отсутствует, недостающие
спрайты и звуки заменяются процедурными заглушками.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| ЛКМ | огонь / заряд / заброс диска |
| ПКМ | удар оружием ближнего боя |
| Space | рывок с неуязвимостью |
| R | перезарядка |
| V | режим огня пистолета |
| Q / G | граната / аптечка |
| F | активный артефакт |
| X | смена оружия ближнего боя |
| E | маяк / магазин / лифт |
| T | доска навыков |
| Esc | пауза |

## Что есть в игре

- 13 школ оружия: 7 огнестрельных и 6 ближнего боя;
- 66 ветвей и 1320 узлов развития;
- процедурные сектора, комнаты, коридоры и магазины;
- 7 типов обычных врагов и 3 босса;
- артефакты, гранаты, элитные враги, система комбо;
- спуск по секторам с ростом сложности;
- CPU-рендер и опциональный OpenGL-режим с выбором адаптера.

## Кооператив (онлайн, MVP)

Одиночная игра не меняется: сеть запускается только через главное меню
→ **ОНЛАЙН**.

1. **Создать игру** — вы хост. На экране показан реальный адрес
   `IP:ПОРТ` (порт по умолчанию 32123). Нажмите Enter, когда все
   подключились.
2. **Подключиться к игре** — введите адрес хоста (например
   `192.168.1.50:32123`) и нажмите Enter.

Как устроено:

- **Хост авторитетен.** Он симулирует мир и всех игроков, проверяет
  попадания, урон, расход патронов, подбор, покупки и цели сектора.
  Клиент присылает только ввод и намерения (до 30 раз в секунду),
  хост рассылает снимки мира 20 раз в секунду.
- **Один мир.** Сид сектора выбирает хост; клиент строит ту же
  геометрию сам тем же генератором (`seed` + глубина + биом), а по сети
  получает только сущности. Это даёт одинаковые комнаты, магазины и
  маяки без пересылки тайлов.
- **Клиент рисует сам.** Сектор строится порциями по 1–2 чанка за кадр
  под экраном «СИНХРОНИЗАЦИЯ СЕКТОРА», поэтому подключение и спуск не
  дают многсекундного фриза. Вспышки выстрелов, гильзы, частицы, цифры
  урона, тряска камеры и звуки боя выводятся на клиенте из разницы двух
  снимков: хост не считает и не рассылает презентацию.
- **Личное:** здоровье, оружие, патроны, деньги, навыки, убийства и
  серия. **Общее:** мир, враги, маяки, лифт, глубина сектора.
- **Награда за убийство** — тому, чей удар был последним (включая
  кровотечение). Добыча достаётся первому, кто её коснулся; предмет
  исчезает у всех одновременно, потому что это решает хост.
- **Маяк** заряжается, пока рядом любой живой игрок; награду получают
  все живые. Магазин открывает каждый у себя, но покупку подтверждает
  хост (проверяет расстояние, баланс и что товар тот же).
- **Смерть и наблюдение.** Павший становится наблюдателем: камера
  цепляется к ближайшему живому соратнику, а `A`/`D` (или стрелки)
  листают остальных живых. Свой HUD (деньги, навыки) остаётся личным.
- **Воскрешение.** Босс гарантированно роняет **осколок души**. Живой
  игрок тратит его на **алтарь возвращения** в стартовой комнате
  сектора (клавиша `E` рядом с алтарём): павший встаёт рядом с 50% HP,
  но теряет половину купленных навыков (первыми сгорают глубокие узлы).
  Алтарь ставится из сида, поэтому виден всем одинаково.
- **Лифт** тоже возвращает павших — в следующем секторе с 40% HP; это
  второй, «бесплатный», но более медленный путь.
- **Присоединиться** можно только до старта вылазки. Максимум — 4
  игрока (1 хост + 3 гостя), версия протокола проверяется.

Ограничения MVP:

- TCP подходит для локальной сети и небольшой задержки в интернете;
  предсказания движения своего героя нет, позиции сглаживаются.
- Запас вокруг клиента — 49 чанков (радиус 3); при уходе дальше чанк
  строится на месте, как и в одиночной игре (до ~65 мс на чанк), но
  фризов в секунды нет.
- Для игры **через интернет** нужен проброс порта на роутере хоста или
  туннель (Radmin/ZeroTier и т. п.). NAT и фаервол сами не обходятся —
  ретранслятора и матчмейкинга в этой версии нет.
- Магазины и дерево навыков доступны всем: клиент видит свою
  прогрессию из снимков, а покупку подтверждает хост (цена, подготовка
  и вторая ветвь проверяются по его состоянию героя).

Код сети живёт в `netplay/` и не зависит от pygame на уровне протокола.

## Структура

```text
main.py                 точка входа
netplay/                кооператив: протокол, TCP, снимки, экран «Онлайн»
game.py                 игровой цикл и состояния
player.py               герой, движение, инвентарь
weapons.py              оружие, заряд, режимы
projectiles.py          пули, взрывы, частицы
enemies.py / bosses.py  враги и боссы
world.py                процедурные чанки и коллизии
descent.py              маяки, лифт и общие цели сектора
hud.py                  интерфейс
graphics_backend.py     выбор адаптера и владелец презентера
render/                 презентеры кадра: CPU/SDL, OpenGL
render_metrics.py       метрики кадра (update/draw/present)
tools/bench_render.py   headless-замер стоимости кадра
assets/                 спрайты, звуки и manifest
```

`video_settings.json` создаётся игрой локально и не входит в репозиторий.
